## Schema facts that bear on the decisions

Read from `mechanistic_pathway_learning/graph/neurotransmission_regulation.py` and
`.../graph/oxidative_regulation.py`:

- `add_release_regulation` keys signs by `(receptor_gene, population)` and **drops any pair that carries two
  signs** (`conflicting_signs_left_out`). So a genuinely region-dependent sign cannot be represented: the choice
  is one sign or no row. The graph has one generic neuron and no region attribute, which is why several
  region-dependent candidates below end as "no row" rather than "both signs".
- `LIGAND_BASES` has no entry for **ATP**. The P2RX7 candidate (P-26) therefore lands in
  `rows_without_a_release_reaction` even if accepted, until ATP's Human-GEM metabolite is added to
  `LIGAND_BASES`. Flagged, not changed.
- `OXIDANT_BASES` admits only: hydrogen peroxide, superoxide, nitric oxide, peroxynitrite, hydroxyl radical,
  4-hydroxynonenal, hypochlorous acid, nitrite, nitrogen dioxide. "lipid hydroperoxides", "glutathione
  depletion", "polyunsaturated fatty acid supply" and "electrophilic phase-2 inducers" resolve to nothing, so
  those candidate rows cannot be placed as written — the schema objection in the unverified file is correct.
- `curated_oxidant_targets.csv` has **no `compartment` column**, so `getattr(row, "compartment", "")` always
  falls back to the cytosolic copy of the oxidant. The `species_evidence` column is free text.
- `curated_oxidant_sources.csv` **does** have `compartment`; `COMPARTMENT_WORDS` matches only
  mitochondri/peroxisom/endoplasmic reticulum/nucle/lysosom/extracellular/intermembrane, so "plasma membrane"
  (as in the accepted NOX1/CYBB/NOX5 rows) falls back to cytosolic. The new NOX3 row below is consistent with
  that precedent.
